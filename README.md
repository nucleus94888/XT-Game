# 半藏 HANZO

以服部半藏為主角的動作冒險遊戲。目前是「手感切片」階段：**一個半藏、一個稻草人、一刀**，
唯一驗收標準是「砍下去爽不爽」。引擎 Godot 4.7.2（免費、開源），目標平台 iOS 優先、Android 之後。

- 線上試玩（iPhone Safari 直接開，可「加入主畫面」變全螢幕）：https://nucleus94888.github.io/XT-Game/
- 工具管線與 iOS 上架流程：[PIPELINE.md](PIPELINE.md)
- 之前的戰國大戰略版本：封存在 `strategy-archive` 分支，沒有刪除。
- 五次 LLM Council 的報告與逐字稿：`docs/council/`（第五次：體力條去留 → 刪體力、改玩家體幹）

## 關卡與故事（詳見 [docs/STORY.md](docs/STORY.md)）

- **第一關：伊賀夜襲** — 今川軍本營。鳥居山門 → 第一院（農家、水井、櫓上的弓兵、足輕巡邏）→ 石階上台地 → 第二院（長屋、土藏、練兵場、武士巡邏）→ 陣屋。陣屋裡副將守著大將：大將一察覺就從後門逃走、門在他身後關上；殺了副將門才開，追出去就過關。
- **第二關：湖畔屋敷** — 大將逃到山下的屋敷。山道俯瞰 → 池泉庭園（石橋、茶室上的弓兵）→ 屋敷一樓（緣側、障子隔間、走廊有武士巡邏）→ 樓梯上二樓（守衛面向樓梯口）→ 奧座敷的大將。從後院鉤上北側露台可以從背後接近。殺了大將鉤上屋頂撤離。
- **第三關：夜之城下町** — 城門已關。大街兩旁一樓二樓交錯的町家，屋頂高低差就是鉤繩路線；十字路口的火之見櫓是最高點；河只有橋能過（武士把守）；城門廣場有侍大將，殺了得念珠，不殺也能從番所屋頂鉤上九公尺城牆出城。
- 走到屋簷下／樓下時上方的屋頂與樓板會自動隱藏，鏡頭看得到室內。
- **成長**：念珠（每關殺大將 +10 最大 HP，最多四枚）與卷軸（每關一卷：手裡劍 ×7、口糧可帶兩份、飛鉤），撿到立刻生效、到檢查點才存檔。沒有攻擊力升級、貨幣、商店、等級。詳見 docs/STORY.md。
- 過關結算時間、擊破、暗殺數、被擊中與被發現次數，評價 影 / S / A / B / C，可直接進下一關。

- 敵人有視野錐與視線遮蔽：頭上白條是警覺度，「？」起疑、「！」發現並呼叫 10 公尺內同伴。出刀有聲音，5 公尺內的敵人會起疑。
- 未察覺的敵人從背後砍 = **暗殺**，一擊必殺、無聲。
- 足輕：長槍，成群；弓兵：保持距離射箭，箭可格擋不可彈反，用閃步躲；武士／武將：戰鬥中一律架刀，正面的刀全部擋下（砍架刀只累積少量體幹），**連擋你第三刀會立刻反擊**；出手前置中有霸體（硬吃刀只受六成傷害）。要傷到他：彈反他的攻擊（體幹 +35、硬直）、手裡劍／鉤繩、或把體幹打滿一刀忍殺。
- 任何敵人被你連打兩下後，下一刀變成不可格擋的「**危**」技（頭上紅字）：只能閃步或拉開距離。
- 敵人連出六刀會「喘」0.8 秒（武將不喘），是破綻。
- **體幹（玩家）**：左上橙條。被敵人格擋 +15、被打中 +25、普通格擋 +10、完美彈反 −10；1.5 秒沒受擊每秒回 20。滿了跪下 2.5 秒不能動不能擋，挨刀 1.5 倍、敵人會立刻追擊；崩壞後 3 秒免疫體幹傷害。多個敵人同時打你：1 秒內第二個以上敵人造成的體幹傷害打五折。沒有體力條。
- 閃步：0.6 秒內最多兩次，之後 0.8 秒不可閃（按鍵顯示倒數）。手裡劍 5 枚、一次只能一枚在空中；打到牆地會插著，走過去撿回；走到檢查點補滿（不顯示提示）。鉤繩拉人冷卻 4 秒（按鍵倒數；鉤牆頂不受限）、同一敵人 6 秒內不能再拉。
- 全速奔跑有靴聲，3.5 公尺內未警戒的敵人會過來查看；潛行時搖桿推一半。暗殺後 1 秒硬直。
- 敵人失去你的蹤影會到最後看到／聽到的位置搜索幾秒再回巡邏；手裡劍打在地上的聲響會把守衛引過去。
- 熄掉燈籠後站在暗處，敵人視野縮短四成。
- 擊倒敵人有機率掉落「忍者口糧」，走過去回 35 HP（目標武將必掉）。
- 走過山門、第一院入口、窄道、第二院入口會「記住此處」；死亡可從最近檢查點重生（敵人全部重置）或整關重來。
- 右上「Ⅱ」暫停：繼續／設定（音量、視角靈敏度、介面大小、左撇子、進階手感調校）／重來／回標題。連點羅盤三下顯示除錯資訊。

## 操作

| 動作 | 觸控 | 鍵盤 |
| --- | --- | --- |
| 移動（相對鏡頭） | 左 60% 畫面任意處按住拖曳（浮動搖桿） | WASD / 方向鍵 |
| 轉視角 | 右側空白處拖曳 | Q / E |
| 攻擊（三段連斬，收刀過半可接下一段） | 右下「攻擊」 | J / Space |
| 閃步（無敵，可取消前置與收刀） | 右下「閃」 | K / Shift |
| 格擋（按住，隻狼式架刀；舉刀後 220 毫秒內擋下＝彈反，對方後仰、體幹 +35） | 右側「格擋」（按住） | L / Ctrl |
| 切換刀／手裡劍 | 攻擊鍵右上小鍵「切換」 | R |
| 手裡劍（切到手裡劍後，攻擊鍵改為按住瞄準、放開射出。瞄準＝過肩鏡頭＋畫面中央白色十字，拖右側視角瞄準，準心附近的敵人會默默鎖定；左搖桿慢速移動。打不到就射到牆上插著可撿回；打地面引開守衛、打燈籠熄燈、打斷弓兵） | 右下「手裡劍」（按住） | J（按住） |

| 爆頭：手裡劍與鉤繩瞄準頭部傷害更高（不另外標示） | — | — |
| 冷卻：閃步連閃兩次後、鉤繩拉人後，按鍵改顯示倒數秒數 | — | — |
| 落下忍殺 | 從屋頂落下時按攻擊，對下方未察覺的敵人一擊必殺 | J |
| 手感調校面板 | 右上「手感調校」 | P / Tab |

稻草人靠近時每 2.8 秒、或 1.5 秒內連吃三刀，會出現「！」然後橫掃，用閃步躲或在它揮出的瞬間格擋彈反。
頭上黃條是「體幹」：被砍、被彈反都會累積，滿了就「體幹崩壞」硬直 2.5 秒，期間任何一刀都是「忍殺」一擊必殺。HP 歸零或忍殺後倒下、1.2 秒後重生。

## 三天驗收流程

1. 打開面板，**先不要看數字**，輪流按「甲・利落 / 乙・沉重 / 丙・流暢 / 丁・電影 / 戊・無料」各砍一分鐘。
2. 挑最爽的一組，再拖滑桿微調；感覺對了按「儲存」。
3. 按「複製數值」把那組參數貼回來給 AI，AI 把它固定成正式預設。
4. 第三天晚上在 iPhone 上砍：爽 → 進第二階段（地圖翻轉成任務生成器）；不爽 → 回 `strategy-archive` 補回饋感，兩週內不再改方向。

## 本機開發

```
# Godot 4.7.2 已安裝在 C:\Users\Win\tools\godot\，雙擊 Godot_v4.7.2-stable_win64.exe → 匯入 hanzo/project.godot
# 或命令列直接跑：
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path hanzo

# 自動試玩 + 截圖（AI 用來看畫面）
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path hanzo ++ --shot=C:/Users/Win/Desktop/XT-Game/build/shots --autoplay

# 戰鬥平衡驗證 bot（對一名武士 1v1 打 N 場，印勝率；--trace 印狀態轉換）
# 目標：連按 bot 勝率 <30%、彈反 bot 勝率 >70%
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path hanzo scenes/level1.tscn ++ --bot=mash --runs=20
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path hanzo scenes/level1.tscn ++ --bot=deflect --runs=20

# 網頁版量觸控延遲：遊戲中連點羅盤三下開除錯，左下會顯示「觸控延遲 avg ms（最差）」

# 關卡檢查：故事流程（第一關）、巡迴截圖（任何關，把半藏傳送到各點各拍一張）
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path hanzo scenes/level1.tscn ++ --story
C:\Users\Win\tools\godot\Godot_v4.7.2-stable_win64_console.exe --path hanzo scenes/level2.tscn ++ --shot=C:/Users/Win/Desktop/XT-Game/build/t2 "--tour=0,0.7,-5;0,3.7,-17"

# 重新產生圖示 / 字型子集
npm run assets
```
